安装

从 GitHub 或国内镜像下载最新的安装包。安装包自带运行环境， 不需要再安装别的东西，也不需要管理员权限。

  1. 双击安装包，按提示选择安装位置。
  2. 安装完成后从开始菜单打开 Oriel。
  3. 首次运行时 Windows 可能提示未知发布者。选择「更多信息」→「仍要运行」。

安装包未做代码签名，所以 SmartScreen 会多问一句。安装包来自本项目的发布页， 校验可以对照发布页上的文件大小与更新时间。

第一次打开

左侧是常用位置和磁盘，上方是前进后退、视图切换、排序和分组。 双击文件夹进入，双击文件用系统默认程序打开。

  • 网格和列表随时切换：Ctrl + 1 / 2。
  • 地址栏可以直接编辑：Ctrl + L。
  • 右键菜单分文件、文件夹和空白处三套，可以在「设置 → 右键菜单」里逐项开关。
  • 每个文件夹会记住自己的视图、排序、分组和滚动位置。
  • 在空白处按住左键拖动可以框选多个项目，按住 Ctrl 拖动则追加选择。

首页

侧边栏最上方的「首页」把每天要用的东西放在一页：常用位置、 各磁盘的剩余容量，以及最近打开过的文件夹。点卡片就能进去。

  • 常用位置、磁盘和最近打开各是一组，点击即打开对应文件夹。
  • 磁盘卡片上的进度条是真实占用，接近满了会变成橙色。
  • 想让每次启动都停在首页：`设置 → 浏览 → 启动位置` 选「首页」。 默认仍是上次停留的位置。

分区查看

把两个文件夹放在一起看：工具栏一级的「分区」分段控件可以选单窗格、 左右两栏、三栏或四象限，切回完整视图也在同一个控件上。

  • 每个窗格独立导航、视图、排序和选择，互不影响。
  • 文件可以直接拖到另一个窗格，也可以复制、剪切、粘贴。
  • 侧边栏和窗口标题跟着当前窗格；点一下窗格就能切换。
  • 窗格右上角的「在完整视图中打开」会回到单窗格并停在该文件夹。

分区里可以浏览、复制、移动、改名和删除。搜索、批量重命名和预览需要回到完整视图。

搜索

搜索框在工具栏右侧，按 Ctrl + F 可以直接跳过去。 默认范围是「此磁盘」，也可以在搜索框左边切换成「当前文件夹」或「所有磁盘」。

  • 空格分词：输入「report 2024」会匹配名字里同时含这两个词的文件，顺序不限。
  • 结果边扫边出现，不必等整块磁盘扫完。
  • 按 Esc 停止搜索并清空结果。
  • 系统目录会被跳过；结果条数或时间到达上限时，状态栏会说明结果可能不完整。

预览

选中文件按 空格，预览面板会在右侧打开。图片、PDF、文本、音频和视频 都能直接看，再按一次空格或按 Esc 收起。预览不会启动外部程序。

批量重命名

选中多个项目后按 F2。查找替换、编号、添加前后缀和大小写可以叠加使用， 右侧会实时列出「原名 → 新名」。

  • 重名、非法字符和空名字会在应用前标出来。
  • 交换两个名字、只改大小写都可以安全完成。
  • 应用后按 Ctrl + Z 可以整批退回原名。

压缩包

zip、7z 和 rar 可以像文件夹一样双击进入，查看目录和文件大小。 选中需要的项目直接解压，或者把整包解压到旁边的文件夹。 压缩包内容在浏览时是只读的。

回收站

Delete 把文件放进 Windows 回收站， Shift + Delete 永久删除并先弹出确认。 侧栏的回收站会列出文件原来的位置和删除时间。

  • 可以还原到原位置；原位置已有同名项时会跳过并说明原因。
  • 可以只清空选中项，也可以清空全部。

系统集成

都在「设置 → 系统」里，只影响当前用户，不需要管理员权限。

开机自启与托盘

  • 开启后，登录 Windows 时静默进入托盘，不会弹出窗口。
  • 托盘图标可以隐藏；隐藏后会同时取消开机自启，避免启动后找不到窗口。
  • 「关闭窗口时最小化到托盘」关掉后，点关闭就是退出。

右键菜单与默认打开方式

  • 可以给文件夹、文件夹空白处和磁盘加上「用 Oriel 打开」。
  • 打开「设为默认资源管理器」后，Oriel 会注册成文件夹的打开方式， 并跳到 Windows 的「默认应用」页面，由你确认。

Windows 不允许程序静默顶替资源管理器。Oriel 不会接管桌面、任务栏和 Win + E；它做的是把文件夹窗口换成自己。 卸载时注册表开关不会自动清理，可以先在设置里关掉。

端口进程

从侧边栏「工具 → 端口进程」进入，也可以在设置里找到。 页面会列出本机正在监听的 TCP 和 UDP 端口。

  • 表格包含端口、协议、地址、进程、PID 和进程路径。
  • 搜索框按端口、协议、地址、进程名或 PID 过滤。
  • 点「关闭」再确认，就会结束占用该端口的进程。
  • 需要管理员权限的进程会提示结束失败，这时要用管理员身份操作。
  • Oriel 自己的本地服务与系统进程受保护，不会在列表里被误关。

结束进程会立即关闭对应程序，未保存的内容可能丢失。 如果不确定是哪个程序，可以先看进程名和路径，或者用搜索框缩小范围。

更新与国内镜像

打开「设置 → 关于」，Oriel 会自动检查新版本。也可以点「重新检查」立即刷新。 下载完成后点「立即安装并退出」，安装程序会接着完成更新。

  • 下载会先尝试国内镜像，再回落到 GitHub。
  • GitHub 打不开或下载很慢时，可以直接去 Gitee 发布页 手动下载安装包。
  • 更新不会动你的偏好设置、文件夹记忆和右键菜单配置。

常见问题

打开后显示「服务未连接」

第一次启动需要几秒钟准备。如果一直显示未连接，打开「设置 → 本地服务」， 点「重启」即可；Oriel 也会在后台自动尝试恢复。

搜索找不到某个文件

先确认搜索范围是不是「当前文件夹」，再检查是否开启了「显示隐藏文件」。 系统目录会被主动跳过；结果条数或时间到上限时，状态栏会给出提示。

分区里能搜索吗

分区窗格专注对照和拖放，搜索、批量重命名和预览请回到完整视图。 点窗格右上角的「在完整视图中打开」即可。

能完全替代资源管理器吗

可以设为文件夹的默认打开方式，也可以挂在右键菜单里。桌面、任务栏和 Win + E 仍由 Windows 管理，这是系统本身的限制。

文件会被上传吗

不会。浏览、搜索、预览、改名、复制和压缩都在本机完成，不联网也能用。

为什么提示未知发布者

安装包没有做代码签名。选择「更多信息」→「仍要运行」即可。

卸载后右键菜单还在

右键菜单和开机自启写在当前用户的注册表里，卸载程序不会自动删除。 卸载前先在「设置 → 系统」里把对应开关关掉即可。
