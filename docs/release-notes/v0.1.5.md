0.1.5 修的是 0.1.4 里还没彻底解决的国内更新问题：Gitee 的 API 会被限流拦截，客户端拿不到版本信息。

## 国内更新

- 更新检查不再依赖 Gitee API，改为读取仓库里的 `update.json`（通过 raw 文件地址，不限流、不被 WAF 拦），API 只作为兜底。
- `update.json` 由发布流程自动生成并提交，内容包含版本号、更新日志、安装包文件名与大小。
- Gitee API 拿不到文件大小时，现在也能从 manifest 里读到，下载完成后的完整性校验不会失效。
- 下载顺序仍然是 **CDN → Gitee → GitHub**。

## 说明

0.1.4 的用户在这一版之后就能自动走国内源；升级到 0.1.5 后，后续版本会优先从 Gitee 下载。
如果你还在 0.1.3 或更早的版本，请直接从 [Gitee 发行版](https://gitee.com/rain-drops/oriel/releases) 手动下载 0.1.5 安装包。

## 修复

- 移除了一段不再使用的旧下载函数，它带着 30 秒总超时，容易让大安装包中途失败。
