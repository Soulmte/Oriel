0.1.8 修掉 0.1.7 报上来的问题，并补上几处长期被吐槽的细节。

## 默认资源管理器

- 修好「关掉开关反而提示写入注册表失败」：关闭是成功，不是错误；开关也不会再卡在开启状态。
- 打开后会回读注册表确认写入成功，失败时给出原因。
- 按 Arke 的做法补齐了 `Folder` 的 `open` / `explore` 动词（`DelegateExecute` 写空），并在写完
  后通知外壳刷新关联，不再需要重启资源管理器。
- 兼容性说明：`SHOpenFolderAndSelectItems`（部分程序「打开文件所在位置」用的就是这个 API）
  在 Windows 上不经过文件关联，任何第三方程序都拦不到；走 `ShellExecute` 的都会被接管。

## 更新改成静默安装

- 「立即安装」不再弹卸载 / 安装向导：exe 用 `/S` 静默安装，msi 用 `/passive` 只显示进度条。
- 只退出 Oriel、后台装完，重新打开即可，不需要先卸载。

## 修好提权后工具卡死

- 重启后只探测「端口有没有人监听」，旧进程正在退出时会被误判为服务已就绪，新进程于是不启动
  自己的服务，进程管理器 / 端口进程 / 磁盘清理 / 卸载工具全部卡在加载。
- 现在用 `/api/health` 校验服务版本：不匹配就等端口释放再自己绑定，绑定失败会重试三次。

## 搜索

- 整盘搜索的时间预算从 10 秒提到 45 秒。
- 进度更新更勤（每 1500 项），状态栏和结果头上都能看到实时扫描数量。
- 多个关键词可以匹配文件夹路径：搜「2024 报告」能找到 `2024\报告.docx`。
- 新增「停止」按钮，随时结束搜索并保留已找到的结果；超时后明确提示结果可能不完整。

## 文件列表

- 新增「多久前」列：`刚刚`、`5 分钟前`、`3 天前`、`2 个月前`。
- 文件夹大小会随刷新和文件变化重新统计，不再一直显示旧值。
- 「列表显示的列」现在可以单独勾选「多久前 / 修改日期 / 大小 / 种类」。

## 预览

- 选中多个项目时显示汇总：总计大小、文件 / 文件夹数量、公用位置，以及可点选的选中项列表。
- 文件夹直接列出里面的前 10 项（名称 + 大小），点文件夹进去、点文件打开。
- ZIP / 7z / RAR 等压缩包直接列出内容，点「浏览」进入压缩包。
- 文本预览带行号、行数 / 字符数、编码；长段落可以切换「换行」，内容可一键复制。
- Markdown 按格式渲染（标题、列表、引用、链接、代码块），并可在「预览 / 源码」之间切换。
- Word / PowerPoint 提取文字预览（标注「仅提取文字」），不再只显示一个图标。
- 图片在透明棋盘格上显示，双击用默认应用打开；SVG 直接渲染（包括 `width="100%"` 这类没有内在尺寸的文件）。
- WebP / TIFF / BMP 也能显示像素尺寸。
- 音频显示大图标 + 播放控件，视频和 PDF 内嵌播放 / 翻页。
- 底部新增「简介」，直接打开属性面板。

## 外观

- 文件夹图标跟随强调色，不再固定为 Finder 蓝。
- 强调色换成应用内取色面板：16 个色卡、4 组渐变预设、色相 / 明度滑杆和色值输入，不再弹系统取色器。
- 强调色可以是渐变：选中行、主按钮和进度条都使用同一组渐变。
