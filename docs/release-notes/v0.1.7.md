0.1.7 让「设置成默认资源管理器」真正生效，并把设置页重新整理了一遍。

## 默认资源管理器

- 开启后会把这个用户的文件夹与磁盘「打开」动作指向 Oriel：其它程序里的路径链接、
  「打开文件夹」按钮、命令行 `start "" "D:\x"` 都会跳进来。
- 关掉开关即删除当前用户的覆盖项，立刻回到资源管理器打开。
- 0.1.6 里这个开关只登记了「打开方式」，所以点了没有任何反应，也没有地方可以确认。

## 修好从别处打开路径

- 带引号或尾部反斜杠的路径（例如 `"D:\dir\"`）以前会被静默丢掉，现在先清洗再判断。
- 传入的是文件而不是文件夹时，打开它所在的文件夹。
- 关于页的「打开发布页」和「查看完整变更」以前点不开：后端把 https 链接当成文件路径校验，
  必然报错。现在网页链接直接交给系统浏览器。

## 设置

- 删除「本地服务」页。
- 系统页新增：删除前确认、图标缓存占用与清理、打开日志目录、以管理员身份重启。
- 浏览页新增：显示缩略图、侧边栏显示「收藏」、列表显示的列（复选，名称列固定）、单击打开。
- 「显示文件扩展名」从外观移到浏览，归到它该在的地方。
- 关于页加上 GitHub 与 Gitee 地址。
- 修掉每次进设置页时开机自启开关重新滑动一遍的问题（先读缓存值，加载期间禁用过渡）。

## 细节

- 侧边栏折叠按钮、「返回文件」不再使用箭头图标。
- 删除确认对话框会区分「移到废纸篓？」和「永久删除？」。
