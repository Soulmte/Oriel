0.1.4 修好了国内更新失败的问题，并带来两个新工具：磁盘清理和卸载工具。

## 更新更可靠

- 更新源改为**编译期写入安装包**，不再依赖用户机器的环境变量。之前 CI 里的镜像配置根本没有进 exe，国内只能连 GitHub，检查更新和下载安装包经常超时。
- 下载顺序固定为 **CDN → Gitee → GitHub**，优先走国内可达的地址。
- GitHub 与 Gitee 并行查询（8 秒超时），不再因为 GitHub 被墙而卡住整个检查。
- 每个镜像下载完都会**校验文件大小**，不完整（比如代理返回的错误页面）会自动删掉并换下一个源。
- 取消固定的总超时，慢速网络也能把安装包下完。
- 启动约 4 秒后自动检查更新，右下角弹出卡片：可以立即更新、稍后提醒，或跳过这个版本。
- 下载进度显示真实字节数与速度；关掉卡片后，下载完成或失败会自动重新弹出。

## 新增：卸载工具

- 读取 HKLM / HKCU / WOW6432Node 的卸载项，列出本机安装的软件。
- 列表支持按**名称 / 占用大小 / 安装时间**排序，再点一次切换升降序。
- 显示每个软件的**实际占用空间**：多线程遍历安装目录（跟随 junction，结果缓存 10 分钟）；遍历失败时回退到注册表里的估算值，并用 `≈` 标出。
- 运行官方卸载程序并等待其退出，然后自动刷新列表。
- 卸载后弹出残留检查：注册表项、安装目录、快捷方式逐项列出，可勾选永久删除。共用目录标黄并默认不勾选，避免误删其他软件的文件。
- 支持静默卸载（无人值守）与「以管理员身份重启 Oriel」。

## 新增：磁盘清理

- 按目录分析磁盘占用，热力图展示哪些文件夹最占空间。
- 顶部地址栏可直接跳到任意文件夹，「前往」会先解析路径：去掉首尾引号、展开 `%VAR%` 环境变量与 `~`，路径不存在时给出提示。
- 在同一路径上再点一次「前往」会重新扫描，而不是毫无反应。

## 修复

- 磁盘清理「前往」点击无效：路径没有解析、同路径不刷新、路径不存在时也没有提示。
- 批量重命名入口在空白处右键中永远不出现（右键先清空选择，导致菜单项被判定为不可用）。现在工具栏铅笔按钮、更多菜单和空白右键都能进入。
- 偶尔双击文件夹没有反应：不再只依赖浏览器的 `dblclick`，900ms 内两次点击同一项即打开。
- 去掉工具栏里排序 / 分组 / 搜索范围三处多余的下拉小箭头。
- 关闭窗口后驻留托盘、再次启动只复用一个实例。

## 其他

- 新增可选的「始终以管理员身份运行」构建：`npm run build:desktop:admin`。默认安装包仍是普通权限（asInvoker）。

完整更新日志也可以在应用的「设置 → 关于」里查看；国内下载地址见 [Gitee 镜像](https://gitee.com/rain-drops/oriel/releases)。
